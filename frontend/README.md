# تطبيق Pi

تطبيق Flutter مصمم للعمل مع منصة Pi، يتيح للمستخدمين تسجيل الدخول باستخدام Pi وإدارة الدفعات.

## الميزات

- تسجيل الدخول باستخدام Pi Network
- إنشاء وإدارة الدفعات
- واجهة عربية مستخدمة
- دعم متعدد المنصات (Android, iOS, Web)

## المتطلبات

- Flutter 3.0.0 أو أحدث
- Dart 3.9.2 أو أحدث

## التثبيت

1. 克隆 المستودع:
   ```bash
   git clone https://github.com/center-net/piApp.git
   ```

2. اذهب إلى مجلد التطبيق:
   ```bash
   cd frontend
   ```

3. قم بتثبيت الحزم:
   ```bash
   flutter pub get
   ```

## الاستخدام

1. قم بتشغيل التطبيق:
   ```bash
   flutter run
   ```

2. للتشغيل على منصة معينة:
   ```bash
   flutter run -d chrome      # للمتصفح
   flutter run -d android     # لأجهزة Android
   flutter run -d ios         # لأجهزة iOS
   ```

## الهيكل

- `lib/main.dart`: نقطة الدخول للتطبيق
- `lib/screens/`: يحتوي على الشاشات المختلفة للتطبيق
- `lib/services/`: يحتوي على الخدمات مثل خدمة المصادقة
- `assets/`: يحتوي على الأصول مثل الخطوط والصور

## التكامل مع Pi

التطبيق يستخدم بروتوكول Pi للمصادقة والدفعات. يجب أن يكون التطبيق مثبتًا على أجهزة تحتوي على Pi Network ليعمل بشكل صحيح.
